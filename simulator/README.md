# XTEINK X4 E-Reader Desktop Simulator

Нативный интерактивный симулятор прошивки **XTEINK X4 (Book Orbit)** для macOS на базе SDL2.

Симулятор компилирует тот же самый исходный C++ код интерфейса (`src/main.cpp`, `src/ui/`, `src/reader/`), что работает на реальном ридере, и рендерит монохромный буфер 800×480 (в портретной ориентации 480×800) в окно на рабочем столе с попиксельной точностью шрифтов и оформления.

---

## Быстрый запуск

В папке `firmware/` выполните:
```bash
./run_simulator.sh
```
или
```bash
make -f simulator/Makefile run
```

## Управление (Клавиатура Mac)

| Клавиша на Mac | Кнопка ридера X4 | Действие |
|---|---|---|
| **Стрелка ВВЕРХ** (`↑`) | `BTN_UP` | Перемещение курсора вверх |
| **Стрелка ВНИЗ** (`↓`) | `BTN_DOWN` | Перемещение курсора вниз |
| **Стрелка ВПРАВО** (`→`) | `BTN_RIGHT` | Следующая страница / карусель книг |
| **Стрелка ВЛЕВО** (`←`) | `BTN_LEFT` | Предыдущая страница |
| **ENTER / RETURN** | `BTN_CONFIRM` | Выбор / Открыть книгу / Подтвердить ввод |
| **ESC / BACKSPACE** | `BTN_BACK` | Назад / Отмена / Закрыть меню |
| **P или ПРОБЕЛ** | `BTN_POWER` | Кнопка питания (сон) |

## Папка MicroSD карты

Симулятор использует локальную папку `simulator/sdcard/`:
* `simulator/sdcard/books/` — сюда можно положить любые `.epub` или `.txt` книги.
* `simulator/sdcard/covers/` — кэшированные обложки книг.
* `simulator/sdcard/config.json` — настройки Wi-Fi и сервера Book Orbit.
